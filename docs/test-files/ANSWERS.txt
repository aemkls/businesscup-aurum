ClaimBack: тестовые документы и ожидаемые результаты
Все документы выдуманы. Ожидаемые цифры посчитаны тем же движком правил, что работает на сайте.
Как проверить: https://businesscup-aurum-delta.vercel.app -> Check my bill -> загрузить файлы -> Continue to your plan -> ввести цифры плана -> Run the check.
Для случаев 1, 3 и 4 цифры плана совпадают с кнопкой «Fill from sample». Для случая 2 введите их вручную.
Если ИИ неверно прочитает строку с фото, сумма может отличаться: тогда загрузите PDF.
